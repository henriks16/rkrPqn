# 우리집 가계부

수입·지출, 대출 잔액, 예금·적금, 카드·현금 사용, 사람별·월별·연도별 현황을 기록하는 가계부 웹앱입니다.

- 로그인 없이 링크만 열면 각자 자기 가계부를 쓸 수 있습니다.
- 기록은 **각자의 기기 브라우저 안에만** 저장됩니다. 서버로 보내지 않으므로 다른 사람은 볼 수 없습니다.
- 휴대폰에서 홈 화면에 추가하면 앱처럼 쓸 수 있고, 인터넷이 없어도 열립니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 가계부 화면 전체 |
| `manifest.webmanifest` | 홈 화면 앱 이름·아이콘 설정 |
| `sw.js` | 오프라인에서도 열리게 하는 파일 |
| `icons/` | 앱 아이콘 |

## GitHub Pages로 올리기

1. [github.com](https://github.com)에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다.
   - Repository name: 예) `gagyebu`
   - **Public** 선택 (무료 계정의 GitHub Pages는 공개 저장소에서 쓸 수 있습니다)
   - **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
4. 이 폴더 안의 파일과 `icons` 폴더를 **통째로 끌어다 놓습니다**. (폴더 자체가 아니라 폴더 *안의* 내용물을 올려야 `index.html`이 맨 위에 옵니다.)
5. 아래 **Commit changes**를 누릅니다.
6. 저장소의 **Settings** → 왼쪽 **Pages**로 갑니다.
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
7. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   `https://내아이디.github.io/gagyebu/`
8. 이 주소를 가족·지인에게 보내면 각자 자기 가계부로 사용할 수 있습니다.

## 휴대폰에 앱처럼 설치하기

- **아이폰(Safari)**: 주소를 연 뒤 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome)**: 주소를 연 뒤 오른쪽 위 ⋮ → **홈 화면에 추가** 또는 **앱 설치**

아이폰은 Safari에서 오래 열지 않은 사이트의 저장 데이터를 지울 수 있으니, 홈 화면에 추가해서 쓰는 것을 권장합니다.

## 백업 (꼭 해 주세요)

기록은 그 기기에만 있으므로, 다음 경우 사라질 수 있습니다.

- 브라우저의 방문 기록·사이트 데이터를 지울 때
- 휴대폰을 바꾸거나 초기화할 때
- 앱(홈 화면 아이콘)을 지울 때

**자산·현황** 페이지 맨 아래 **데이터 백업**에서

- **백업 파일 저장**: 지금까지의 기록을 `.json` 파일로 저장합니다. 한 달에 한 번쯤 저장해 두세요.
- **백업 불러오기**: 저장해 둔 파일로 기록을 되살립니다. 다른 기기로 옮길 때도 씁니다.

## 앱을 고친 뒤 다시 올릴 때

1. 바뀐 파일을 저장소에 다시 올립니다 (같은 이름이면 덮어씁니다).
2. `sw.js` 맨 위의 `VERSION` 값을 `gagyebu-v2`처럼 바꿔서 함께 올립니다.
   이걸 바꿔야 이미 설치한 사람들의 앱도 새 버전으로 바뀝니다. (앱을 한 번 열고 닫으면 다음 실행부터 반영됩니다.)

사용자들의 기록은 각자의 기기에 있으므로, 앱을 새로 올려도 기록은 지워지지 않습니다.
